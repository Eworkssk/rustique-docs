Eloquent models,
laid out as Rust structs.

Rustique is an active-record ORM for Rust with the API you know from Laravel: models, a fluent query builder, relations, migrations and factories. Every column gets a compile-time constant, so typos fail the build. One API speaks MySQL and Oracle.

A typo in a column name fails the build.

#[rustique::model] gives every column a constant and every relation a typed name. Pass them to the query builder and a misspelling is a compiler error with a suggestion, not an Unknown column at runtime.

User::ID User::NAME User::EMAIL User::CREATED_AT User::POSTS User::EMIAL

One query. Two grammars.

Write the query once. The grammar quotes identifiers, rewrites limits, builds upserts and stores JSON the way each database wants it. Tested against MySQL 8.4 and Oracle XE 21c.

Relations are fields. Loading is explicit.

A relation is a Rel<T> field with an attribute, not a column. Eager-load a nested path and Rustique runs one statement per level. Turn on prevent_lazy_loading in debug builds and an accidental N+1 becomes an error.
